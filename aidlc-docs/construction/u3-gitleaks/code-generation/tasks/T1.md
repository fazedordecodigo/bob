## Apoio de teste (em `tests/test_gitleaks.py`, nomes exatos)
- `_SCRIPT: bytes` = `b'#!/bin/sh\ncase "$1" in\n  --version) echo "gitleaks version 8.30.1" ;;\n  version) echo 8.30.1 ;;\n  *) exit 2 ;;\nesac\n'` (só responde a `--version` e `version`; qualquer outro argumento sai 2).
- `_archive(members: list[tuple[str, str, bytes]]) -> bytes`: tar.gz em memória (`tarfile`, `mode="w:gz"`); cada item `(nome, tipo, dados)` com tipo `"file"` (modo 0o755), `"symlink"` (alvo = `dados.decode()`) ou `"dir"`.
- Fixture `server`: `http.server.ThreadingHTTPServer(("127.0.0.1", 0), …)` em thread daemon; atributos `routes: dict[str, list[tuple[int, bytes]]]` (cada GET consome o 1º item da lista do caminho; o último se repete; caminho sem rota → 404) e `requests: list[str]` (`"GET <caminho>"`); `base` = `http://127.0.0.1:<porta>`; desliga no teardown.
- Fixture `fake` (usa `server`, `monkeypatch`, `tmp_path`): `monkeypatch.setattr(gitleaks, "platform_key", lambda *a, **k: ("linux", "x64"))`; `monkeypatch.setenv("BOB_GITLEAKS_BASE_URL", server.base)`; `TMPDIR` próprio: `monkeypatch.setattr(tempfile, "tempdir", str(tmp_path / "tmp"))` (pasta criada); `sleeps: list[float]` com `monkeypatch.setattr(gitleaks.time, "sleep", sleeps.append)`; `home = bob_home({"BOB_HOME": str(tmp_path / "bh")})`; função `serve(data: bytes, sha: str | None = None)` que põe `/gitleaks_8.30.1_linux_x64.tar.gz` → `[(200, data)]` e faz `monkeypatch.setitem(gitleaks.ASSETS, ("linux", "x64"), ("gitleaks_8.30.1_linux_x64.tar.gz", sha or sha256(data)))`.
- `_leftovers(tmp: Path) -> list[str]`: nomes `bob-gitleaks-*` em `tmp`.
