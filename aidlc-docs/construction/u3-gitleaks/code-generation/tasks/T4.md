## Objetivo
`bob check --gates secrets` acha o gitleaks em `BOB_HOME/bin` antes do `PATH`, com a mesma regra do `bob doctor` (CT8, ADR 0019), para que um projeto instalado pelo comando único não saia `4` com "missing tool: gitleaks".
