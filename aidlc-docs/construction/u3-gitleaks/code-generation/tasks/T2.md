| R2 | `doctor._locate(executable)` passa a ser `return user_dirs.locate_binary(executable)`. Vale para `node` e `gitleaks`. Nada mais muda em `_cli_version`. |

Valores resultantes iguais aos de hoje. `doctor.py` fica sem nenhum sha256 literal e sem a URL literal. |
| R4 | `doctor._install_then_report(lang)`: `code = install_npm_dependencies(lang)`; `code != 0` → devolve `code`. Senão `gitleaks.ensure_gitleaks(ctx.home)`; `GitleaksError as exc` → `StepResult("failed", error=reason(exc))`; ok → `StepResult("installed", installed=(msg("setup.item_gitleaks", version=gitleaks.VERSION),))`.
