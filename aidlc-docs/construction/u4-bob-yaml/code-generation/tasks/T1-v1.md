## Contrato do módulo
```python
"""Gerador do bob.yaml (C05, CT7): padrões do README e paths.include derivado."""

CONFIG_NAME = "bob.yaml"
ConfigState = Literal["created", "preserved", "created_no_code"]

@dataclass(frozen=True)
class ConfigResult:
    state: ConfigState
    include: tuple[str, ...]

def render_config(include: Sequence[str]) -> str: ...
def write_default_config(project: Path) -> ConfigResult:
    """Cria bob.yaml se não existe (CT7). Nunca altera um existente."""
```
Imports permitidos: `json`, `os`, `collections.abc.Sequence`, `dataclasses.dataclass`, `pathlib.Path`, `typing.Literal`, `yaml` (só `yaml.YAMLError`), `bob_quality.config` (`DEFAULT_EXCLUDE`, `_SUFFIX_LANGUAGE`, `_excluded`, `load_config`), `bob_quality.suite_fingerprint` (`_listed_files`), `bob_quality.yaml_text` (`parse_yaml`). Use `suite_fingerprint._listed_files(project)` por atributo do módulo (`from bob_quality import suite_fingerprint`), para os testes 15 e 21 poderem trocá-la; importe `load_config` pelo nome (`from bob_quality.config import load_config`) e use `os.replace` via `import os`, para os testes 15–18 trocarem `init_config.load_config` e `init_config.os.replace`. Nenhuma dependência nova. Funções privadas à vontade.

## Regras de comportamento
| # | Regra |
|---|---|
| R1 | `target = project / CONFIG_NAME`. Se `target.exists() or target.is_symlink()` → retorna `ConfigResult("preserved", ())` sem chamar o git, sem ler e sem escrever nada. |
| R2 | Candidatos = `suite_fingerprint._listed_files(project)`. `ToolError` sobe sem mudança. |
| R3 | Um nome conta como código só se valem as três condições: `Path(name).suffix in _SUFFIX_LANGUAGE`; `(project / name).is_file() and not (project / name).is_symlink()`; e `not _excluded(Path(name), tuple(DEFAULT_EXCLUDE))`. |
| R4 | Nome de código sem `/` → há código na raiz. Com `/` → o primeiro componente é pasta candidata, se não começa com `.`. |
| R5 | `"src"` entre as candidatas → `include = ("src",)`, `state = "created"`. Senão, se há candidatas → `tuple(sorted(candidatas))`, `"created"`. Senão, se há código na raiz → `(".",)`, `"created"`. Senão → `(".",)`, `"created_no_code"`. |
| R6 | `render_config(include)` devolve exatamente o texto abaixo, com `<INCLUDE>` = `"[" + ", ".join(itens) + "]"`. Item `"."` → `"."` (com aspas). Outro item fica como está se `parse_yaml(f"[{item}]") == [item]`; senão (inclusive quando `parse_yaml` levanta `yaml.YAMLError`), vai como `json.dumps(item, ensure_ascii=False)`. |
| R7 | `tmp = project / f"bob.yaml.tmp-{os.getpid()}"`. Dentro de um `try`: `tmp.write_bytes(render_config(include).encode("utf-8"))`; `load_config(tmp, project)`; `os.replace(tmp, target)`. Em qualquer exceção: `tmp.unlink(missing_ok=True)` e a mesma exceção sobe (`raise`). Em sucesso, retorna `ConfigResult(state, include)`. |
