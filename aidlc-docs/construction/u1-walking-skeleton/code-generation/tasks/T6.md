## Objetivo
Todo PR e todo push na `main` rodam `sh scripts/verify-install.sh` no Linux x64, num job próprio, sem segredos e sem `sudo`.

## Arquivo a criar: `.github/workflows/verify-install.yml`
Conteúdo fixado (chaves e valores; a ordem das chaves é esta):
- `name: verify-install`
- `on:` `pull_request:` (sem filtro) e `push:` com `branches: [main]`.
- `permissions:` `contents: read` (só isso).
- `concurrency:` `group: verify-install-${{ github.ref }}`, `cancel-in-progress: true`.
- `jobs:` um job `linux-x64`: `runs-on: ubuntu-latest`, `timeout-minutes: 20`, passos, nesta ordem:
  1. `uses: actions/checkout@<mesmo SHA e comentário de versão do ci.yml>`
  2. `uses: actions/setup-python@<mesmo SHA do ci.yml>` com `python-version: "3.12"`
  3. `uses: actions/setup-node@<mesmo SHA do ci.yml>` com `node-version: "<NODE_FLOOR do scripts/install.sh>"` (hoje `22.18.0`, igual ao `ci.yml`)
  4. `name: Harness`, `run: sh scripts/verify-install.sh`
  5. `name: Guardar o temporário em falha`, `if: failure()`, `uses: actions/upload-artifact@cf430e030ddbb5b0abf93d22962f4752f3646cd9 # v7.0.2` (tag `v7.0.2`, publicada 2026-10-07 07:08 UTC-3; SHA conferido pela API do GitHub em 2026-10-18 23:4x UTC-3) com `name: verify-install-tmp`, `path: ${{ runner.temp }}/bob-verify.*`, `retention-days: 7`, `if-no-files-found: ignore`. Para isso o passo 4 roda com `env: TMPDIR: ${{ runner.temp }}`.
- Sem `secrets.`, sem `sudo`, sem `pull_request_target`, sem `write` em `permissions`.
