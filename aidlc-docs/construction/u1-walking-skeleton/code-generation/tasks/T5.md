## Sintaxe e saída
- `sh scripts/verify-install.sh [--only <id>[,<id>...]] [--help]`, rodado na raiz de um checkout do bob (senão `verify-install: uso: rode na raiz do checkout do bob (não achei scripts/install.sh).`, `1`).
- `--only`: ids de `STEP_IDS`; `9` = todos os ids que começam com `9`. Id desconhecido → `verify-install: uso: passo desconhecido <id>. Passos: 1 2 3 4 7 8 9b.`, `1`. `--only` sem valor ou arg desconhecido → `verify-install: uso: <arg>. Rode com --help.`, `1`. Os passos rodam na ordem de `STEP_IDS`, não na ordem pedida.
- `--help` → stdout `uso: sh scripts/verify-install.sh [--only <id>[,<id>...]]` + linha `passos: 1 2 3 4 7 8 9b` + linha `VERIFY_REMOTE=1 usa o GitHub em vez do espelho local.`; `0`.
- Saída `0` se todos os passos rodados passam; `1` no primeiro que falha (para ali) ou se o preparo falha. Uso inválido: `1`, antes de qualquer preparo.
- Ao sair com `1`, o temporário fica e a última linha do stderr é `verify-install: temporário guardado em <T>`. Ao sair com `0`, o temporário é apagado.
