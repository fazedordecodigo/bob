## Objetivo
`bob setup [--lang]`, rodado na raiz de um projeto git, confere Python e Node, instala as ferramentas npm (só se faltar), grava as skills em `.agents/skills`, roda `bob doctor` e imprime o resumo do CT3; sai `0` só se tudo passou e o doctor saiu `0`.

## Regras de comportamento (R1–R14)
| # | Regra |
|---|---|
| R1 | `bob_home(env)`: `BOB_HOME` não vazio → precisa começar com `/`, senão `ValueError(value)`; `root = Path(value)`. Senão `XDG_DATA_HOME` não vazio e começando com `/` → `Path(xdg) / "bob-quality"` (relativo é ignorado). Senão `Path(env.get("HOME") or Path.home()) / ".local" / "share" / "bob-quality"`. Sem `resolve()` (não segue symlink, não lê o disco). |
| R2 | `run_setup`: `ctx.project = project.resolve()`; `ctx.version` = versão do pacote; `ctx.home = user_dirs.bob_home()`. `ValueError` do `bob_home` → erro `setup.bob_home_relative` (R9), nenhum passo roda. |
| R3 | Passos em ordem de `STEPS` (lido na hora da chamada). Para no primeiro `failed`. Depois de cada passo não `failed`: imprime no stdout `t(lang, "setup.step_ok", step=<id>)` e, para cada aviso, `t(lang, "setup.warning_line", step=<id>, text=render(aviso, lang))`. |
| R4 | `step_projeto`: `git` ausente (`shutil.which`) → `failed`, `setup.git_missing`. `git rev-parse --show-toplevel` com `cwd=ctx.project` (código ≠ 0, `OSError`, ou `Path(stdout.strip()).resolve() != ctx.project`) → `failed`, `setup.not_git_root` com `path=ctx.project`. Senão `unchanged`. |
| R5 | `step_runtimes`: `ValueError` de `_python_floor()` → `failed`, `setup.python_floor_bad` (`value` = texto lido). `sys.version_info[:2] < floor` → `failed`, `setup.python_old` (`found=platform.python_version()`, `floor="A.B"`). Depois `npm_tools.node_range()` (`PinSourceError` → `failed`, `setup.step_reason` com `step="runtimes"`, `reason=reason(exc)`). `_node_version_text()` `None` → `failed`, `setup.node_missing`. Texto que não casa inteiro `v(\d+\.\d+\.\d+)` ou `not doctor.node_admits(doctor.node_pin(), <sem o v>)` → `failed`, `setup.node_out` (`found` = texto como veio). Placeholders: `range=str(node_range())`, `floor="A.B.C"` (de `floor`), `major=str(floor[0])`. Senão `unchanged`. |
| R6 | `step_npm`: `pins = npm_tools.pinned_npm_versions()` (`PinSourceError` → `failed`, `setup.step_reason`, `step="npm"`). Se `npm_tools.npm_prefix()` não levanta `ToolError` e `installed_npm_version(prefix, nome) == versão` para todo `nome, versão` de `pins` (`ToolError` em qualquer um = falta) → `unchanged`, sem `npm ci`. Senão `code = npm_tools.install_npm_dependencies(ctx.lang)` (a saída atual dele vai para o stdout como hoje); `code != 0` → `failed`, `setup.npm_failed`; `0` → `installed` com `installed=(msg("setup.item_npm"),)`. |
| R7 | `step_skills`: `install_skills.install_project_skills(ctx.project, ctx.version)`. `SourceError` → `failed`, `setup.skills_source` (`detail=str(exc)`). `OSError` → `failed`, `setup.skills_write` (`path` = `exc.filename` se houver, senão `.agents/skills`; `detail=exc.strerror or type(exc).__name__`). Resultado: `installed` não vazio → `installed=(msg("setup.item_skills", names=", ".join(installed)),)` e status `installed`; senão status `unchanged`. `preserved`: um `Text` por caminho, com o caminho relativo a `ctx.project` (POSIX), motivo pela 1ª regra que casa: está em `unmarked` → `setup.preserved_no_marker`; é symlink → `setup.preserved_symlink`; é arquivo → `setup.preserved_file`; senão → `setup.preserved_foreign`. `warnings`: um `setup.warn_no_marker` por item de `unmarked`, depois um `setup.warn_duplicate` por item de `duplicates` (caminhos relativos). |
| R8 | Exceção não tratada num passo (`Exception`) → resultado `failed` com `setup.internal_error` (`step=<id>`, `kind=type(exc).__name__`). Não propaga. |
| R9 | Falha (passo ou R2): imprime no stderr `t(lang, "setup.error", reason=render(error, lang))`; imprime o resumo (R10) com o que já foi juntado e `setup.doctor_not_run`; devolve `4`. |
| R10 | Resumo no stdout, nesta ordem: `setup.summary`; `setup.installed` com `items` = itens de todos os passos, separados por `", "`, ou `t(lang, "setup.nothing")`; uma linha `setup.preserved` por item; uma linha `setup.warnings` por aviso; `setup.doctor` com `code` = código do doctor ou o texto de `setup.doctor_not_run`. A última linha é sempre a do `bob doctor`. Sem linha de perfil (U6). |
| R11 | Sem falha: `code = doctor.run_doctor(install=False, lang=lang)` (saída dele vai para o stdout como hoje), depois o resumo, e devolve `0` se `code == 0`, senão `4`. |
| R12 | `bob setup` não lê nem escreve `package.json`, lockfiles ou `node_modules` do projeto, não pergunta nada (não lê stdin) e não chama `sys.exit`. |
| R13 | `bob setup --lang` segue `resolve_language` como os outros comandos. Uso inválido (`bob setup --foo`, `bob setup --config x`) → `4` pelo caminho de uso do `cli.py`. |
| R14 | Os passos não imprimem nada, exceto `install_npm_dependencies` dentro de `step_npm` (saída existente; I11). |
