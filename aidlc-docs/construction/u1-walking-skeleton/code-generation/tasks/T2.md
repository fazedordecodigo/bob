## Regras de comportamento (R1–R12)
| # | Regra |
|---|---|
| R1 | `version` precisa casar inteiro com `\d+\.\d+\.\d+`; senão `ValueError(f"versão inválida: {version!r}")`, antes de qualquer escrita. |
| R2 | Skills e atribuição vêm de `_skills(source)` (mesma validação do CLI; `SourceError` sai antes de qualquer escrita). Destino: `dest = project / ".agents" / "skills"`, criado com `mkdir(parents=True, exist_ok=True)`. Nenhum outro diretório é criado ou escrito no projeto. |
| R3 | Conteúdo esperado de `<nome>`: cada arquivo regular sob a pasta da skill na fonte (`os.walk(followlinks=False)`; caminho relativo → bytes), mais cada arquivo de atribuição (`_attribution`) na raiz da pasta com o próprio nome, mais `.bob-version` com `f"{version}\n"` (UTF-8, LF). |
| R4 | `target = dest / <nome>` não existe → grava (R8); nome vai para `installed`. |
| R5 | `target` é symlink ou arquivo → não toca; vai para `preserved`. |
| R6 | `target` é pasta sem `target/.bob-version` como arquivo regular → não toca; vai para `preserved` e `unmarked`. |
| R7 | `target` é pasta com `.bob-version`: se o conjunto de arquivos (sem symlinks; um symlink dentro conta como diferença) e os bytes de cada um são iguais ao esperado (R3) → nada é escrito, nome vai para `unchanged`; senão → regrava inteira (R8), nome vai para `installed`. |
| R8 | Gravação: monta a pasta completa em `dest / f".{nome}.bob-tmp-{os.getpid()}"` (cópia com `shutil.copy2`, `.bob-version` gravado com `write_bytes`); se `target` existe, `os.replace(target, dest / f".{nome}.bob-old-{os.getpid()}")`; depois `os.replace(tmp, target)`; depois apaga a pasta `.bob-old`. Em `OSError` no meio, a exceção sobe (o temporário pode ficar; R10 limpa na próxima execução). |
| R9 | Entradas de `dest` fora do manifesto: pasta (não symlink) com `.bob-version` regular → `shutil.rmtree` (skill aposentada; não aparece no resultado). Qualquer outra (pasta sem marcador, arquivo, symlink) → `preserved`. |
| R10 | Entradas de `dest` cujo nome casa `^\..+\.bob-(tmp|old)-\d+$` → apagadas (sobras). Outros nomes que começam com `.` → ignorados (não aparecem no resultado). R10 roda antes de R4–R9. |
| R11 | Duplicatas: para cada `root` em `DUPLICATE_ROOTS` e cada nome do manifesto, `project / root / nome` é pasta (não symlink) com `SKILL.md` regular → entra em `duplicates`. Não apaga, não lê `.bob-version` (o instalador antigo não gravava). |
| R12 | Só stdlib; `install_skills.py` continua rodando em modo script. `main`, `_install`, `_remove_retired` e o CLI não mudam. `install_project_skills` não chama `_remove_retired`. |
