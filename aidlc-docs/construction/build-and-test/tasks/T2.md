# ET — Stage 3.6 Build and Test — Tarefa T2: Portabilidade macOS (`darwin-arm64` / `darwin-x64`) revelada pelo ensaio `E0` (`release.yml`)

## Metadados
- **Projeto:** `bob` (`fazedordecodigo/bob`)
- **Estágio:** `3.6 Build and Test`
- **Tarefa:** `T2`
- **Branch de trabalho:** `aidlc/build-and-test/t2-macos-portability`
- **Branch base:** `main` (commit `55c4de7a00b10459313bea85dbdfb8f71698ddf5`)
- **Escopo estrito:** Corrigir os 4 desvios de portabilidade macOS (`darwin-arm64` e `darwin-x64`) identificados na primeira execução do ensaio `E0` (`release.yml`, run `40129456138`, que falhou em `verify (macos-arm64)` e `verify (macos-x64)` com as mesmas 11 falhas em `pytest`):
  1. `src/bob_quality/install_skills.py`: `_remove_path` chamava `path.unlink()` capturando apenas `IsADirectoryError` (`EISDIR`, Linux); no macOS/BSD, `unlink(2)` em diretório levanta `PermissionError` (`EPERM`), quebrando a remoção/substituição de diretórios em `bob setup`.
  2. `src/bob_quality/security_gate.py`: `_detached` não resolvia symlinks no diretório retornado por `tempfile.mkdtemp(prefix="bob-semgrep-")`; no macOS (`/var` → `/private/var`), o `semgrep` resolve o `cwd` para `/private/var/...` enquanto `--config` recebia `/var/...`, alterando o `check_id` de `.semgrep.<regra>` para `var.folders....<regra>`.
  3. `scripts/install.sh`, `docs/install-prompt.en.md`, `docs/install-prompt.pt-BR.md` e `tests/test_docs_pins.py`: no macOS, `/bin/sh` é `bash` em modo POSIX, que ao iniciar sem `SHELL` no ambiente (`envp`) define uma variável local não exportada `SHELL=/bin/zsh` via `getpwuid()`; ler `ENVIRON["SHELL"]` via `awk` garante que `SHELL` ausente no ambiente caia em `$HOME/.profile` conforme CT3/CT18 tanto no Linux quanto no macOS.
  4. `tests/test_eslint_in_process.py`: o stub de `eslint` em `_raw` lia `/proc/self/fd/0` (exclusivo do Linux) em vez de `os.path.sameopenfile(0, os.open(os.devnull, os.O_RDONLY))`.

def test_remove_path_uses_rmtree_for_real_dir_without_unlink(
    tmp_path: Path, monkeypatch: pytest.MonkeyPatch
) -> None:
    folder = tmp_path / "owned"
    folder.mkdir()
    (folder / "SKILL.md").write_bytes(b"# skill\n")
    real_unlink = Path.unlink

    def _bsd_unlink(self: Path, missing_ok: bool = False) -> None:

            raise PermissionError(1, "Operation not permitted", str(self))
        real_unlink(self, missing_ok=missing_ok)

    assert not folder.exists()
