## Regras de comportamento (R1–R9)
| # | Regra |
|---|---|
| R1 | As versões npm esperadas vêm só de `dependencies` do `package.json` empacotado (`src/bob_quality/package.json`; no checkout é symlink para a raiz; no wheel é arquivo real). Nenhuma versão npm literal em `doctor.py`. |
| R2 | A faixa do Node vem só de `engines.node` do mesmo arquivo. Forma aceita: casamento inteiro (`fullmatch`) de `>=(\d+)\.(\d+)\.(\d+) <(\d+)` com `N = A + 1` (N = 4º grupo, A = 1º grupo). Hoje: `>=22.18.0 <23`. |
| R3 | Cada valor de `dependencies` é `X.Y.Z` exato: casamento inteiro do `_EXACT_SPEC` já existente (`\d+\.\d+\.\d+`) e tipo `str`. `^`, `~`, pré-release, número ou objeto: erro. |
| R4 | Paridade: `package-lock.json` tem, para cada dependência, `packages["node_modules/<nome>"].version` igual ao `package.json`, e `packages[""].dependencies` igual a `dependencies`. Divergência → teste falha e cita pacote e as duas versões. (Só teste; sem código de produção.) |
| R5 | A versão npm encontrada vem só do prefixo do bob: `_prefix_npm_version(pin.npm_package)` (existente: `<_npm_root()>/node_modules/<pacote>/package.json`, campo `version`, com `name` igual ao pacote). Sem fallback para executável no `PATH` nem para `node_modules` do cwd. |
| R6 | O doctor não lê `Path.cwd()`, `cwd/node_modules` nem `cwd/node_modules/.bin`. Executáveis (`node`, `gitleaks`, ferramentas Python) vêm só de `shutil.which`. |
| R7 | O doctor não escreve no projeto. Bytes alterados no cwd = 0. |
| R8 | Sem `--install`, o doctor roda só 2 subprocessos, nesta ordem: `node` e `gitleaks`. |
| R9 | Saída do doctor preservada byte a byte: mesmas linhas `doctor.version`, mesma ordem de `PINS`, mesmos textos de instalação. Só muda a origem do valor esperado. |

## Códigos de saída e saídas

|---|---|---|---|
| Tudo bate | linhas `doctor.version` (igual a hoje) | vazio | `0` (`PASSED`) |

If the packaged `package.json` cannot be read, the doctor prints one stderr line, as in `bob doctor: package.json: could not read <path> (<error>). Reinstall bob.`, and exits `4`.

O `bob doctor` lê as versões npm e a faixa do Node do `package.json` empacotado com o bob. Um bump de `package.json` e `package-lock.json` basta, sem mudar código. O doctor lê cada ferramenta npm só do prefixo do próprio bob. O `node_modules` e o `node_modules/.bin` do projeto não mudam o resultado. Se o `package.json` empacotado não puder ser lido, o doctor imprime uma linha no stderr, como em `bob doctor: package.json: não consegui ler <caminho> (<erro>). Reinstale o bob.`, e sai com `4`.
