### Bloco en (com `{link}`)
````markdown
## Install

Run this at the root of your project (a git repository):

```bash
curl -fsSL https://github.com/fazedordecodigo/bob/releases/latest/download/install.sh | sh
```

For messages in Brazilian Portuguese, add `-s -- --lang pt-BR` after `sh`.

The command installs bob in `BOB_HOME` (by default `~/.local/share/bob-quality`), links `bob` in `~/.local/bin`, and adds that folder to the `PATH` in your shell profile. Then it runs `bob setup` in the project, which installs the pinned npm tools, gitleaks `8.30.1`, the skills in `.agents/skills`, `bob.yaml`, and the pre-push hook. It uses no `git clone`, no plugin, and no `sudo`.

Requirements: Python 3.10 or newer, Node `>=22.18.0 <23` with npm, git, curl, and `sha256sum` or `shasum`. Linux and macOS, on x64 and arm64.

### Alternative: ask your AI agent

This path does not use `install.sh`. Paste [the AI agent prompt]({link}) into your agent at the project root; it installs step by step and reaches the same result. If the two paths differ, the one-line install wins.

## Update

```bash
bob update
bob --version
```

`bob update` reads the latest release. When it is newer than your bob, it downloads that release's `install.sh`, checks its sha256, and runs it in the project. When only the project is behind, it runs `bob setup`. `bob --version` shows the bob version and the version of the project skills.
````

````markdown
## Instalar

Rode na raiz do seu projeto (um repositório git):

```bash

O comando instala o bob em `BOB_HOME` (por padrão `~/.local/share/bob-quality`), liga o `bob` em `~/.local/bin` e põe essa pasta no `PATH` do perfil do seu shell. Depois roda o `bob setup` no projeto, que instala as ferramentas npm pinadas, o gitleaks `8.30.1`, as skills em `.agents/skills`, o `bob.yaml` e o hook de pre-push. Não usa `git clone`, plugin nem `sudo`.

Requisitos: Python 3.10 ou mais novo, Node `>=22.18.0 <23` com npm, git, curl e `sha256sum` ou `shasum`. Linux e macOS, em x64 e arm64.

### Alternativa: pedir ao seu agente de IA

Este caminho não usa o `install.sh`. Cole [o prompt para agente de IA]({link}) no seu agente, na raiz do projeto; ele instala passo a passo e chega ao mesmo resultado. Se os dois caminhos divergirem, vale o comando único.

## Atualizar

```bash
bob update
bob --version
```

O `bob update` lê a última release. Se ela for mais nova que o seu bob, baixa o `install.sh` dela, confere o sha256 e o roda no projeto. Se só o projeto está atrasado, roda o `bob setup`. O `bob --version` mostra a versão do bob e a das skills do projeto.
````
