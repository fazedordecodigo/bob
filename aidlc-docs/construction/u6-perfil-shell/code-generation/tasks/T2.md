## Objetivo
O `bob setup` lê `BOB_INSTALL_PROFILE` (CT6 v2) e imprime `  perfil do shell: <texto>` / `  shell profile: <texto>` no resumo, logo antes de `  bob doctor:`. A linha sai também no resumo parcial. Sem a variável, ou com valor fora dos 4 formatos, nada muda.
