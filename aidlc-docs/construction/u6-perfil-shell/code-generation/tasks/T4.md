## Desenho da medida (fechado pelo arquiteto)
- **Raiz "fora do `HOME`"** = `tmp_path` do teste. Lá ficam o projeto (`git_project`, que é o `cwd` da instalação), o espelho (`tmp_path/mirror`), o `TMPDIR` (`tmp_path/tmp`) e, no 2º teste, o `ZDOTDIR` (`tmp_path/zdot`).
- **`HOME`** = `tmp_path_factory.mktemp("outside-home") / "home"`, uma pasta irmã de `tmp_path`, fora da raiz medida. O log do `bob` falso (`FAKE_BOB_LOG`) fica em `home.parent / "bob.log"`, também fora da raiz.
- **Snapshot** (`_tree`): para cada caminho sob a raiz, inclusive `.git/`:
  - arquivo → modo, tamanho, `mtime_ns` e sha256;
  - pasta → modo;
  - symlink → destino.
  O `mtime` de pasta fica fora, porque o `mktemp -d` do `TMPDIR` cria e apaga a pasta de trabalho, e isso muda o `mtime` da pasta pai sem deixar arquivo.
- **Medida:** `_tree_diff(antes, depois)` = caminhos que entraram, saíram ou mudaram. Esperado: `{}`. Com `ZDOTDIR` fora do `HOME`: exatamente `["zdot/.zshrc"]`.
- **O que é real e o que é dublê** (o alvo são as escritas do próprio `install.sh`):
  - Real: `/bin/sh` com o `scripts/install.sh` da branch, `git`, `curl`, `sha256sum`, `mktemp`, `rm`, `mkdir`, `ln`, `chmod`, `tail`, `grep` e o resto do `_toolbox` (symlinks para o sistema), `python3 -m venv` e `pip install` do wheel.
  - Dublê, como em todos os testes de instalação deste arquivo:
    - o espelho HTTP local em `127.0.0.1` (fixture `server` e `_mirror`), para não usar rede;
    - o wheel falso (`_fake_wheel`): o `bob setup` só grava o `FAKE_BOB_LOG`. As escritas do `bob setup` no projeto são o produto (CT3, ADR 0013: "tudo em `BOB_HOME` e no projeto") e ficam fora desta medida;
    - `node` e `npm` como stubs do `_toolbox`: o `install.sh` só lê a versão deles.
- **Ambiente:** o `_run` monta o ambiente do zero: `HOME`, `TMPDIR`, `PATH` do toolbox, `LANG` e os extras. Sem `XDG_*` nem `BOB_HOME`, então o `BOB_HOME` é `$HOME/.local/share/bob-quality` (ADR 0013) e o cache do `pip` fica em `$HOME/.cache`. O `PATH` não tem `$HOME/.local/bin`, então o passo `perfil` grava.

```python
def _tree(root: Path) -> dict[str, tuple[object, ...]]:
    found: dict[str, tuple[object, ...]] = {}
    for path in sorted(root.rglob("*")):
        rel = path.relative_to(root).as_posix()
        if path.is_symlink():
            found[rel] = ("symlink", os.readlink(path))
        elif path.is_dir():
            found[rel] = ("dir", stat.S_IMODE(path.stat().st_mode))
        else:
            info = path.stat()
            digest = hashlib.sha256(path.read_bytes()).hexdigest()
            found[rel] = (
                "file",
                stat.S_IMODE(info.st_mode),
                info.st_size,
                info.st_mtime_ns,
                digest,
            )
    return found


def _tree_diff(
    before: dict[str, tuple[object, ...]],
    after: dict[str, tuple[object, ...]],
) -> dict[str, tuple[tuple[object, ...] | None, tuple[object, ...] | None]]:
    return {
        rel: (before.get(rel), after.get(rel))
        for rel in sorted(before.keys() | after.keys())
        if before.get(rel) != after.get(rel)
    }


def _outside_run(
    git_project: Path,
    base: str,
    tmp_path: Path,
    home: Path,
    extra: dict[str, str],
) -> subprocess.CompletedProcess[str]:
    return _profile_run(
        git_project,
        base,
        home.parent,
        home,
        {"TMPDIR": str(tmp_path / "tmp"), **extra},
    )
```

`_outside_run` reusa `_profile_run` (`FAKE_BOB_ENV=1`). Ele passa `home.parent` como pasta do log, para o `bob.log` ficar fora da raiz medida, e põe o `TMPDIR` dentro dela.
