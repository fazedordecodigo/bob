O changelog é o [CHANGELOG.md](https://github.com/fazedordecodigo/bob/blob/main/CHANGELOG.md) na raiz do repositório. Ele é o registro das mudanças de comportamento. Cada nota é escrita em inglês e depois em português.

A seção atual é `Unreleased`. Ela inclui, entre outras entradas, o modo fail do DRY, a detecção de linguagem, os gates de segurança e de segredos, o id estável do waiver de mutação, o churn e a faixa de Node que o `bob doctor` aceita. Leia o arquivo para o texto exato. Esta página não o copia.
